# Installation Guide - Bash Automation Toolkit

## System Requirements

### Supported Operating Systems
- Ubuntu 18.04 LTS or newer
- Debian 10 or newer
- CentOS 7 or newer
- RHEL 7 or newer
- Fedora 30 or newer

### Required Packages
```bash
# Ubuntu/Debian
sudo apt update
sudo apt install -y bash coreutils grep awk sed tar gzip rsync

# RHEL/CentOS/Fedora
sudo yum install -y bash coreutils grep gawk sed tar gzip rsync
